# Deterministic pipeline spine with LLMs at fixed nodes

The system is a deterministic code pipeline — intake → Identity Graph → acquisition → extraction → inference → Dossier assembly → matching → Verdict rendering — with LLM calls confined to fixed nodes (extraction, psychometric inference, synthesis) and Session Browsing as the only agentic component. Rejected: agent-orchestrated end-to-end investigation (non-deterministic, expensive, and Evidence Traces degrade into whatever the agent felt like citing — breaking ADR 0005's auditability guarantee) and spine-plus-escalation-agent hybrid (attractive later add-on, but doubles the surface area before the core is proven). Consequence: every stage is cacheable and re-runnable, cost per run is predictable, and debugging means replaying stages rather than re-prompting an agent.
