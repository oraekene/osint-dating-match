# Similarity-first matching with Dealbreaker gates

The match computation is weighted similarity across Dossier layers, with weights taken from the User's stated priorities; complementarity contributes only on a few evidence-backed axes (extraversion pairing, activity-level balance), because the relationship-science literature supports similarity on values and attitudes and largely debunks broad complementarity. Dealbreakers are evaluated as pre-scoring veto gates: a hit terminates the evaluation with an explanation rather than deducting points — mixing vetoes into a score produces absurd outputs like "82% match despite listed dealbreaker." Rejected: pure embedding cosine distance (blind to dealbreakers and priority structure) and predictors trained on public speed-dating datasets (those measure short-run attraction in artificial settings, not relationship outcomes — overfitting to a proxy). Consequence: the matcher needs an explicit priority-weights input UI and a gate-evaluation stage that runs before any scoring.
