# Cross-platform Identity Graph with confidence-scored links

A submitted handle is only the seed: the system pivots from it to enumerate the same username across 3,000+ sites (Maigret/WhatsMyName manifests), then corroborates each candidate with avatar perceptual hash, display-name and bio similarity, linked URLs, location, and email/phone existence checks. We rejected single-platform scope (not OSINT, just scraping; profile too thin) and username-only matching (same-name-different-person false positives). The rejected-alternative risk is worth recording: in a dating product, a false-positive attribution means telling the User defamatory things about an innocent stranger — so every link in the Identity Graph carries a confidence score, and low-confidence links are excluded from profiling rather than averaged in. Consequence: a dedicated identity-resolution subsystem sits between ingestion and profiling, and its precision matters more than its recall.
