# Layered Dossier with mandatory Evidence Trace

Every profile is a five-layer structure (Identity Facts → Interest & Lifestyle → Psychographics → Relational Signals → Logistics), and every claim in it must carry an Evidence Trace: a pointer to the specific post/photo/datum supporting it plus a confidence score. Claims without citable evidence are excluded rather than guessed. We rejected interests-only scope (skips the psychometric core that motivates the project) and psychometrics-first output without grounding (degenerates into an algorithmic horoscope; inference from thin public data has wide error bars that an uncited score would hide). Consequence: the inference pipeline must emit (claim, evidence, confidence) triples end-to-end — this shapes the storage schema and forbids free-form LLM summaries as final artifacts — and the match report can always answer "why do you say that?" by citing raw observations.
