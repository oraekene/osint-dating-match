# Dual-mode consent model: Recon + Deep Dive

The original pitch was unilateral only: submit any handle, profile it, verdict. We rejected pure unilateral (legally radioactive — GDPR has no clean lawful basis for profiling a non-consenting third party, and platform ToS prohibit it) and pure two-sided-consent (commercially clean but guts the demo — there is no "vet a stranger" flow). Instead the system has two profiling modes. **Recon**: unilateral, public-web data only — the OSINT showcase; annotated as demo-only, never commercially shippable. **Deep Dive**: consent-gated, built from the Subject's connected accounts/data exports — the Apply Magic Sauce pattern; annotated as the only legally clean route to deep, non-public profiling. Consequence: the pipeline has two ingestion paths feeding one profiling core, and the match engine must tolerate the wildly different data richness the two modes produce.
