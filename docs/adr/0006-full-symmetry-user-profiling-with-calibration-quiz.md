# Full-symmetry User profiling with Calibration Quiz

The User's own Dossier is built exactly like a Subject's — Session Browsing, tiered scraping, Deep Dive exports — plus one extra instrument: a short self-report psychometric quiz at intake. Rationale: match quality requires comparably-built dossiers on both sides, and the project's credibility hinges on validating psychometric inference against something real. The quiz gives a person where we hold both inferred and self-reported traits, turning "trust the magic" into measurable engine accuracy. Rejected: Recon-only symmetry (no ground truth, thin self-dossier) and intake-questionnaire-only (dossiers built by different methods are not comparable, poisoning the match score). Consequence: intake includes a quiz step, and the system reports inference-vs-self-report deltas as a standing engine-quality metric.
