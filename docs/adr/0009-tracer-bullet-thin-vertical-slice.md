# Tracer bullet: thin vertical slice on public-friendly platforms

The first build slice runs one handle end-to-end through the entire spine — Identity Graph enumeration + corroboration → Reddit/GitHub/YouTube content scraping → LLM extraction and inference → five-layer Dossier with Evidence Traces → similarity score against the quiz-anchored self-Dossier → tiered Verdict page. Session Browsing and Deep Dive exports are deliberately deferred. Rejected: majors-first (starting with the most fragile, detection-prone component risks stalling the project at step one with nothing else standing) and inference-first (cheapest way to de-risk the science, but nothing demos until everything is done). Consequence: every later capability — Session Browsing connectors, Deep Dive export ingestion, escalation agents — bolts onto joints that already exist and are proven.
